# 한국 수출 통계 대시보드

공개 주소: https://jaehochoidev-star.github.io/export-import-data/

## 화면

- 산업통상부: 20대 품목의 월별 수출액·12M MA·YoY와 8개 요약 지표. 기존 보관 자료와 공식 PDF 수치를 연결합니다.
- 관세청: 10대 품목·총계·반도체 제외 총계를 모멘텀 순으로 정렬한 시그널 보드. 구간 YoY, 최근 9구간 추세, 최근/직전 3구간 평균 차이, 당월누적 YoY, 36구간 TTM과 TTM YoY를 제공합니다. 행의 상세 버튼으로 전체 기간 그래프와 계산 표를 확인합니다. 시그널은 최근 3구간 평균 YoY와 모멘텀을 사용하는 자체 분류이며 기준을 화면에 공개합니다.
- KOSIS · 물량과 생산: 수출금액·물량 YoY 비교와 반도체·자동차·화학·철강·석유정제 5개 업종의 생산·출하·재고. 최근 3년/5년/전체 기간을 선택하고 행을 눌러 YoY, 생산지수·12개월 이동평균, 원자료를 확인합니다.

산업통상부와 관세청은 품목 분류가 다르며 금액을 서로 합산하지 않습니다. 비교에 필요한 월이 없으면 지표를 비워 둡니다.

## 저장하는 자료

- `data/history.json`: 2025년 7월 이전의 기존 보관 수치. 추가 수집하지 않는 초기 이력이며 원문 PDF 대조는 미완료입니다.
- `data/reports/YYYY-MM.json`: 각 월 산업통상부 공식 보고서에서 추출한 수치와 PDF 해시. 같은 보고서의 수정치는 Git 변경 이력에 남습니다.
- `dist/data/products.json`: 과거 이력과 새 공식 자료를 합친 전체 월별 데이터. 겹치는 월은 새 공식 수치를 우선합니다.
- `data/ministry.json`: 저장소에 보존하는 누적 원본입니다. 배포할 때 이 파일에서 웹용 데이터를 다시 만듭니다. 새 PDF에서 제외된 오래된 월도 삭제하지 않으며 그래프와 지표는 누적 전체 자료를 사용합니다.
- `data/customs/YYYY-MM-DD.json`: 관세청 수집 시점별 수치와 응답 해시. 키는 저장하지 않습니다.
- `dist/data/customs.json`: 관세청 최신 누적 이력.

공식 공표 YoY가 있으면 우선 사용합니다. 상태 분류는 자체 기준이며 화면에서 계산 방법을 확인할 수 있습니다. 보관 자료는 공식 PDF에서 직접 추출한 것으로 표시하지 않습니다.

## 정기 갱신과 배포

GitHub Actions `Publish dashboard`:

- 매월 2일 10:00 한국시간: 전월 산업통상부 보고서를 정부 정책브리핑에서 검색 → PDF의 20대 품목 표 확인 → 기존 데이터와 병합 → 검사 → Git commit/push → Pages 배포.
- 매월 2·12·22일 10:00 한국시간: 관세청 인증키가 등록된 경우 공식 API를 조회 → 과거 수정치 반영 → 수집본과 누적 데이터 저장 → 검사 → Git commit/push → Pages 배포.
- 수동 `Run workflow`: 두 자료를 갱신한 뒤 저장·배포합니다.
- `main` 코드 push: 저장된 데이터로 검사·배포합니다. 외부 자료는 다시 수집하지 않습니다.

봇 push는 다음 workflow를 자동 실행하지 않으므로, 데이터를 저장한 같은 실행에서 직접 배포합니다. 새 자료를 찾지 못하거나 검증에 실패하면 push·배포하지 않아 기존 공개 자료를 유지합니다. 공개 저장소의 예약 실행은 GitHub 정책에 따라 비활성화될 수 있으므로 Actions 실패·비활성 상태를 확인하세요. 예약 시간은 실행 대기열에 따라 지연될 수 있습니다.

산업통상부 추출기는 현재 연간 합계+13개월 형식을 지원합니다. 표 형식이 달라지면 잘못된 수치를 저장하지 않고 실패합니다. 수동 복구 시 `config/report.json`의 검증된 보고서 설정을 수정하고 `python scripts/fetch-report.py`를 실행할 수 있습니다.

## 관세청 연결 (최초 1회)

1. https://www.data.go.kr/data/15157908/openapi.do 에서 활용신청합니다. 서비스명은 **관세청_수출 주요품목별 10일 단위 잠정치 통계**입니다.
2. 저장소 Settings → Secrets and variables → Actions → New repository secret에 `CUSTOMS_API_KEY`라는 이름으로 공공데이터포털 인증키를 등록합니다. 키는 소스코드나 채팅에 넣지 않습니다.
3. Actions → Publish dashboard → Run workflow를 실행합니다.

최초 조회는 2024년 1월부터입니다. 관세청 API는 매월 11일·21일·익월 1일에 각각 1~10일·1~20일·월 전체를 제공합니다. 매번 저장된 전체 기간을 다시 조회하여 정정 내역도 반영합니다. 2026년 9월 13일 실제 API 연결과 97개 누적기간의 저장·배포를 확인했습니다. API 응답 형식이 명세와 다르면 기존 자료를 보존하고 실패합니다.

현재 관세청은 수출 API를 연결합니다. KOSIS는 별도의 공식 지수를 사용하며, KOSIS 키로 관세청 API를 호출할 수 없습니다.

## 로컬 실행

- `node scripts/serve.mjs`: http://127.0.0.1:4173/
- `node --test`: 지표와 화면 데이터 검사
- `python scripts/build-data.py`: 저장소의 누적 원본으로 웹용 데이터 재생성 (외부 조회 없음)
- `python -m pip install -r requirements.txt`
- `python -m unittest discover -s tests -p "test_*.py"`: 수집기 검사
- `python scripts/update-monthly.py`: 전월 공식 보고서 검색·누적
- `python scripts/fetch-customs.py`: 환경변수 CUSTOMS_API_KEY로 관세청 수집

현재 공개 화면은 `dist/`입니다. 샘플 생성기는 정기 실행에서 사용하지 않습니다. 샘플 생성기를 실행하면 실자료를 덮어쓸 수 있으므로 주의하세요.

## KOSIS · 물량과 생산

- 인증: 저장소 Actions Secret `KOSIS_API_KEY`. 브라우저·공개 JSON에는 키를 포함하지 않습니다.
- 실행: `Update KOSIS and publish` → `Run workflow`, 또는 매주 월요일 10:00 한국 시간. 기존 산업통상부·관세청 일정과 별도입니다.
- 최초 수집: 2015-01~2026-07, 17개 지표 × 139개월. 한국은행 수출금액지수 `301/DT_403Y001`, 수출물량지수 `301/DT_403Y002`, 국가데이터처 전국 산업별 원지수 `101/DT_1F02001`의 T10·T11·T12를 사용합니다.
- 업종의 정확한 명칭: 반도체 제조업 / 자동차 및 트레일러 제조업 / 화학 물질 및 화학제품 제조업; 의약품 제외 / 1차 철강 제조업 / 코크스 연탄 및 석유정제품 제조업. 산업통상부 수출품목과 동일한 범위로 간주하지 않습니다.
- `config/kosis.json`: 공식 표·항목과 기준연도, 업종 선택 기준.
- `data/kosis/raw/*.json`: 공식 API 관측값을 월별로 병합한 원자료. 겹치는 월은 수정값을 반영하고 이전 버전은 Git 이력에 보관합니다.
- `data/kosis.json`: 누적 정규화 데이터. `dist/data/kosis.json`은 여기서 재생성합니다.
- 매번 2015년 이후 자료를 확인해 과거 수정치도 반영합니다. 응답에서 오래된 월이 빠져도 저장된 월은 삭제하지 않습니다. 모든 지표가 검증된 뒤 저장하며, 기준연도·단위·분류가 달라지면 자동 연결을 중단합니다.
- 변경이 있을 때만 commit/push와 배포를 진행합니다. 최근 자료 반영일은 데이터가 바뀐 수집일, 매번의 확인 시각은 Actions 실행 요약에서 확인합니다.
- YoY는 정확히 12개월 전과 비교하며 MA12와 3개월 평균은 중간 결측이 있으면 계산하지 않습니다. 원지수끼리 빼서 물량을 추정하거나 금액·물량 YoY 차이를 가격 상승률로 표시하지 않습니다.
- 로컬 수집: `node scripts/fetch-kosis.mjs` (환경변수 KOSIS_API_KEY 필요).
- 연결 오류·일시적 서버 장애는 최대 5회 재시도하며 대기 간격을 10초, 30초, 60초, 60초로 늘립니다. HTTP 상태와 KOSIS 오류코드만 기록하고 인증키·요청 URL·원문 오류는 남기지 않습니다. 인증 만료나 잘못된 조회 조건은 즉시 실패합니다. 긴 서버 대기 요구가 있으면 반복 요청하지 않고 종료합니다. 실패 시 누적 자료와 공개 사이트를 유지합니다.

## FRED · 금리와 원자재

- Actions Secret: `FRED_API_KEY`. 키는 브라우저나 공개 자료에 넣지 않습니다.
- 자동 갱신: 매일 10:00 한국 시간. `Update FRED and publish`에서 수동 실행할 수도 있습니다.
- 미국 국채 2·5·10년물과 10년−2년 금리차, 은·구리, WTI·브렌트, 옥수수·밀·대두 11개 요청 중 10개를 연결합니다. 은 코드 `PSILVUSDM`은 공식 페이지 404로 확인되어 `enabled: false`로 보류합니다. `config/fred.json`에 공식 시리즈와 단위·주기를 정의합니다.
- API에서 2000년부터 원래 주기의 관측치를 수집합니다. `data/fred/raw/`에 공식 메타데이터·관측치를, `data/fred.json`에 누적 시계열을 보관하고 `dist/data/fred.json`으로 화면을 만듭니다. 같은 날짜 수정치를 갱신하고 과거 날짜는 삭제하지 않습니다.
- 활성 10개 지표의 수집과 단위·주기 검증이 모두 끝난 뒤 파일을 저장합니다. 통신 오류가 나면 기존 자료를 유지하며 인증키·요청 URL·오류 본문은 로그에 남기지 않습니다.
- 금리 변화는 직전 유효 관측치 대비 %p, 일별 유가 변화는 직전 유효 관측치 대비 %, 월별 원자재는 전월·전년 동월 대비 %와 12개월 이동평균입니다. 월별 계산에 필요한 달이 없으면 계산하지 않습니다. 음수 유가는 그대로 보관하고 변화율 분모가 0 이하이면 —로 표시합니다.
- 금리차 검산은 세 지표가 모두 있는 날짜에만 수행합니다. 반올림 오차 0.01%p를 허용하며 FRED 금리차를 임의로 계산값으로 덮어쓰지 않습니다.
- 모든 그래프에 가로·세로 그리드와 단위를 표시합니다. 1년/3년/5년/전체 기간 선택, 최근 원자료 표, 누적 데이터 다운로드를 제공합니다.
